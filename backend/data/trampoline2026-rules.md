# 2026年深圳市青少年蹦床公开赛

# 竞赛规程

## 一、组织单位

指导单位：广东省体操技巧协会

主办单位：深圳市体育运动学校

## 二、竞赛日期及地点

2026年12月6日

深圳市体育运动学校

## 三、参赛单位

深圳市内各区体校、俱乐部、小学、幼儿园及个人

## 四、竞赛项目（共17项）

### （一）大网项目（3项）

U14组蹦床个人

U10组蹦床个人

U8组蹦床个人

### （二）小网项目（14项）

U12组男子蹦床个人、女子蹦床个人

U9组男子蹦床个人、女子蹦床个人

U8组男子蹦床个人、女子蹦床个人

U7组男子蹦床个人、女子蹦床个人

U6组男子蹦床个人、女子蹦床个人

U5组男子蹦床个人、女子蹦床个人

小学组蹦床操、幼儿组蹦床操

## 五、参赛办法

### （一）大网项目：

U14组：2012年1月1日至2015年12月31日出生者；

U10组：2016年1月1日至2017年12月31日出生者；

U8组：2018年1月1日以后出生者；

### （二）小网项目

U12组：2014年1月1日至2016年12月31日出生者；

U9组：2017年1月1日至2017年12月31日出生者；

U8组：2018年1月1日至2018年12月31日出生者；

U7组：2019年1月1日至2019年12月31日出生者；

U6组：2020年1月1日至2020年12月31日出生者；

### 蹦床操：

小学组：2014年1月1日至2019年12月31日出生者；

幼儿组：2019年1月1日以后出生者。

## 六、竞赛办法：

（一）仲裁委员及裁判员由大会统一调派。

（二）比赛办法：

1. 大网项目：

2. 比赛由两套动作组成，取两套成套得分之和评定最终名次。

3. 成套均由十个动作组成。

4. U14组第一套动作需完成特定要求，否则每缺少一个特定动作扣2分。

5. U14组第二套需完成自编套路，中间不可以做无难度分值动作，否则视为成套中断；重复动作只计算数量不计算难度。

6. U10组第一套动作需完成特定要求，否则每缺少一个特定动作扣2分。

7. U10第二套完成自编套路，无难度限制；重复动作只计算数量不计算难度。

8. U8组第一套按照规定动作进行评分，如出现与规定动作顺序、姿态不符，直接视为中断。

9. U8组第二套需完成自编套路，无难度限制；重复动作只计算数量不计算难度。

10. 小网项目：所有组别均按照规定动作进行评分，以20分为满分，进行技术、姿态扣分，评定最终名次；

11. 蹦床操项目：蹦床操竞赛执行中国蹦床与技巧协会审定的《2025年蹦床操评分规则》

（三）各组别各项目进行一场制比赛，直接决出成绩决定名次，得分高者，名次列前；得分相等，名次并列。

（四）运动员的出场顺序由组委会抽签决定。

（五）参加大网项目比赛需穿着体操服，参加小网项目需穿着合身的运动服，蹦床操比赛的服装须统一。

## 七、奖励办法

1. 各项目按运动员最后得分录取前八名排定名次，并颁发证书。

2. 蹦床操比赛成绩按照：特等奖30%、一等奖30%、二等奖40%的比例按组别录取，并颁发证书。

3. 若比赛中出现名次并列，将名次并列的下一个或几个名次空出。

4. 未上场参赛的运动员不发放获奖证书。

5. 设“优秀教练员”奖由组委会评选。

6. 设“优秀组织”奖，同一单位报名人数达15人及以上，颁发优秀组织奖。

## 八、其他

1. 本次比赛不收取任何费用，用餐、交通、保险等费用自行解决。

2. 运动员参加比赛时须携带有效证件(二代身份证)原件，上场前需核对身份证。

3. 最终解释权归深圳市体育运动学校。

### 大网项目：U14组规定动作

1. 一个腹弹或背弹动作；

2. 腹弹或背弹后有一个空翻连接动作；

3. 一个两周空翻；

4. 一个360度或540度以上的转体空翻动作。

### 大网项目：U10组规定动作；

1. 至少要有不同的3个单周空翻动作；

2. 一个腹弹或背弹动作。
