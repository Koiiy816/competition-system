# 武术报名自动复用参赛者编号

同一赛事内以完整的姓名、出生日期、证件号确定身份。单位、账号及性别不参与身份拆分；相同三要素跨单位、跨账号报名复用编号，每个项目仍有独立报名记录。

姓名去除首尾空格，生日按日期比较，证件去除首尾空格并忽略大小写。不同姓名、生日或证件号使用不同编号；三要素不完整时不按同名自动归并。

完整身份生成identityKey，并通过数据库(competition, identityKey)唯一索引保证并发请求不会创建两个档案。旧编号合并后停用并保留历史别名。编号共用不授予其他账号的编辑权限，报名user和schoolName保持原样。

会务费先按编号汇总全赛事有效项目，一至两项300元，之后每增加一项100元。最早有效报名的单位行显示个人总费，其他单位行显示已计费。筛选及账号权限只限制可见明细，不重新计算收费基准。

历史完整资料用 scripts/reconcileAthleteIdentities.js 先预览，再用 --apply --operator=<管理员ID> --report=<受保护备份文件> 执行。保存原档案、受影响报名和操作人，完整资料冲突及缺失记录进入待核查清单，不能误报为全部人员已核实。
