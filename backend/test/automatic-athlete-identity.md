# 武术报名自动复用参赛者编号

参赛单位无需选择人员编号或“新增人员”。报名提交后由后端按以下范围匹配：同赛事、同提交账号、同所属单位内，证件号码、姓名、性别一致时复用原编号。每个项目仍创建独立报名记录 `_id`。

证件号码去除首尾空格并忽略大小写；姓名去除首尾空格。复用前仍核对已有出生日期，资料冲突时拒绝提交，不会以新编号绕过。只有证件相同但姓名或性别不同，不会合并为同一人。

没有匹配人员时使用证件、姓名、性别和单位生成稳定请求键，结合现有 `(competition, user, requestKey)` 唯一索引，确保跨页面和并发请求只创建一个编号。已有迁移编号或人工建立的旧请求键同样可以复用，无需重新执行历史补号。

如果历史上已经存在多个相同资料的编号，返回409要求管理员核对，不自动合并报名或成绩。管理员后台保留人工关联选择；参赛单位页面移除选择及其必选校验。武术单位报名仍需填写证件号码。

测试覆盖：不同请求键复用、证件大小写/空格/正则特殊字符、六次并发创建、同证件不同姓名或性别、不同单位/账号隔离、出生日期冲突、迁移旧编号复用、历史多编号冲突、空证件拒绝，以及原有编辑/费用/补号回归。

部署需更新并重建前后端镜像；本次不批量改写现有业务编号或报名记录。
